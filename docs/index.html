The Rules · 台规

台面上真实存在的每一条规则。

不是简化版。桌面上的每个选项，都能在澳门现行《「Black Jack」或「二十一点」法定规章》或场馆台规里找到出处；参数差异按厅房逐档写明。

01

无底牌制

庄家只先开一张明牌，全部闲家行动完才补第二张。分门与加注遇庄家 Blackjack只失原注，不额外吞掉加注部分。

02

六门独立结算

每门单独下注、单独要牌与结算。同桌闲家一律明牌，所有人的牌你都看得见 —— 这也是能算牌的前提。

03

三种附加注

任何对子、幸运 7、13 以上／以下；另有五张牌与早投降，按场馆与厅房逐项开关，不是每张台都有。

04

会员与贵宾卡

六套官方档位按积分升级；贵宾卡为申请制，按累计有效投注、单次最大投注、到访天数三维审核，获批后长期保留。

05

七档厅房台规

从中场洗牌机到超级贵宾厅 8 副牌靴，牌副、穿透率、销牌与发牌顺序逐档不同，进门之前先看表。

06

算牌工具

流水数、真数、剩余牌与切牌位置实时显示；洗牌机台会直接说明为什么计数在这里失效。

Glossary · 术语

先把词说清楚，再谈策略。

这一页反复出现的九个词，几乎决定了你对「赌场到底怎么赚钱」的全部理解。

有效投注Turnover

每局实际下注额的累计，与输赢无关。分牌、加倍按追加后的总额计；这也是会员积分的唯一计价基础。

庄家优势House Edge

长期每下注 100 元的期望损失。21 点主游戏约 0.5%，附加注普遍在 5%–31% 之间。

穿透率Penetration

牌靴发到切牌卡前已发出的牌占比。越高，剩余牌的信息越充分，计数越有效。

流水数Running Count

Hi-Lo 体系下 2–6 记 +1、7–9 记 0、10 与 A 记 −1 的累计值，随每张明牌更新。

真数True Count

流水数 ÷ 剩余牌副数。把「还剩多少牌」折算进计数，才可用于调整下注与策略。

连续洗牌机CSM

每局把用过的牌立即洗回牌靴，剩余牌构成始终接近初始比例，算牌因此失效。

S17 / H17Soft 17

庄家软 17 停牌还是继续要牌。H17 对玩家更不利，约多付 0.22 个百分点。

五张牌Five-Card Rule

五张不爆可弃牌、按半注结算的特殊规则，仅部分贵宾厅开放，对玩家有利。

邀约制Invitation Only

贵宾资格由场馆按流水、单注、到访与稳定性综合评估发出，玩家无法主动购买或解锁。

Questions · 问答

关于台规与积分，常被问到的八件事。

因为赌场赚的是流水上的抽水，不是某一局的输赢。按有效投注计分，玩家赢钱也照样累积积分；按输赢计分则会出现「赢家没分、输家满额」的荒谬结果，也会诱导玩家为了积分故意输。

贵宾厅的准入是邀约制：除了累计投注，还要看单次最大投注、到访天数与流水是否稳定。系统只会给出状态标签（暂未进入 / 基础候选 / 顶层候选），最终是否邀约由场馆评估，模拟器不会自动授予。

一次性大额流水在风控看来是「突击式充值」，不代表长期客户价值，也常与套利、洗钱特征重合。真实赌场更偏好分散在多个月份、到访稳定的流水结构，因此模拟器会对「80% 流水集中在 7 天内」打稳定性扣分。

算牌依赖「已出牌与剩余牌的构成差异」。CSM 每局把用过的牌立即洗回牌靴，剩余牌构成永远接近初始比例，真数不会再拉开，计数自然失去意义。中场普遍使用 CSM，正是为了压制算牌。

6:5 把 Blackjack 的赔付从 3:2 降到 1.2 倍，单这一项就让庄家优势抬高约 1.4 个百分点；再叠加庄家软 17 要牌，低额台对玩家的劣势远高于高额区。这不是「小台小玩」，而是更贵的同一款游戏。
